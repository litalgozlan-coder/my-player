# שירים מגוגל דרייב בנגן

הסקריפט רץ בחשבון הגוגל שלך, כך שאין צורך לשתף תיקיות או ליצור חשבונות נוספים.
הקבצים נשארים פרטיים. רק מי שמחובר לנגן עם אחד מחשבונות הספוטיפיי שברשימה בקוד יכול לשמוע אותם.

## הפעלה (פעם אחת, כ־5 דקות, מהמחשב)

1. להיכנס ל־https://script.google.com עם החשבון lital.gozlan@gmail.com וללחוץ **פרויקט חדש**.
2. למחוק את מה שכתוב, להדביק את כל התוכן של `Code.gs` ולשמור (💾).
3. למעלה לבחור בפונקציה **test** וללחוץ **הפעלה**. גוגל יבקש אישור הרשאות:
   **בדיקת הרשאות → בחירת החשבון → מתקדם → מעבר לפרויקט (לא בטוח) → אישור**.
   (ה"לא בטוח" מופיע כי זה סקריפט שלך ולא אפליקציה מוכרת.)
4. **פריסה (Deploy) → פריסה חדשה** → ⚙️ **אפליקציית אינטרנט (Web app)**:
   - **הפעלה בתור:** אני
   - **למי יש גישה:** כל אחד (Anyone)
   - **פריסה**
5. להעתיק את **כתובת האפליקציה** (מסתיימת ב־`/exec`) ולשלוח ל־Claude.

## Family Link

לאשר בטלפונים של הילדים את `script.google.com` ואת `googleusercontent.com`.

## שינוי תוכן

לעדכן את הרשימות בראש הקוד, לשמור, ואז:
**פריסה → ניהול פריסות → ✏️ → גרסה: גרסה חדשה → פריסה**. הכתובת נשארת אותה כתובת.
